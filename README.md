# Machine Learning Projects

A collection of practical machine learning projects implemented in Python.

## Projects

### 1. Customer Churn Classification
Binary classification of telecom customers to predict churn.
- Data preprocessing and feature encoding
- Handling class imbalance
- K-Nearest Neighbors, Decision Tree, and Random Forest
- Cross-validation and hyperparameter tuning
- Evaluation using classification metrics and a confusion matrix

[Open project](churn-classification/)

### 2. Auto MPG Regression
Regression models for predicting vehicle fuel efficiency (MPG).
- Exploratory data analysis and visualization
- Data preprocessing
- Linear Regression, Ridge, and Random Forest
- Cross-validation and hyperparameter tuning
- Model evaluation and residual analysis

[Open project](auto-mpg-regression/)

### 3. YOLO Object Detection
Object detection using the Ultralytics YOLO framework.
- Dataset preparation and splitting
- Model training and evaluation
- Predictions on test images

[Open project](yolo-object-detection/)

## Technologies

Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, imbalanced-learn, Ultralytics YOLO.
