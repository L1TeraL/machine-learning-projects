# Auto MPG Regression

A machine learning project for predicting vehicle fuel efficiency using regression models.

## Project Overview

The goal is to predict a vehicle's fuel consumption efficiency, measured in miles per gallon (MPG), using its technical characteristics.

## Methods

- Exploratory data analysis
- Data cleaning and missing value handling
- Feature preprocessing
- Linear Regression
- Ridge Regression
- Random Forest Regressor
- Cross-validation
- Hyperparameter tuning
- Model comparison using MAE, RMSE, and R²
- Residual analysis
- Actual-versus-predicted visualization

## Technologies

- Python
- pandas
- NumPy
- scikit-learn
- Matplotlib

## Dataset

The dataset is stored in `data/auto-mpg.data`.

## How to Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the script from this directory:

```bash
python main.py
```

## Visualizations

Generated charts and model evaluation plots are stored in the `images/` directory.
